# 30-Day Build Plan

Don't buy anything during these 30 days. Start with Grok, Claude Free, ChatGPT Free, Google Sheets/Forms/Drive, and the WhatsApp Business app.

## Phase 1 · Days 1–7 — Foundation

- [ ] **Founder:** decide the items marked `[FOUNDER DECISION]` (prices, payment terms, launch end date, business email)
- [ ] Create the `LocalBoost CRM` sheet from `crm/*.csv`
- [ ] Create Drive folders: `LocalBoost/Leads`, `LocalBoost/Customers`, `LocalBoost/Templates`
- [ ] Set up the Grok bots: Hadi, Saad, Delivery coordinator, Quality controller (`00-operating-rules.md` + own file)
- [ ] Set up the Claude Project: LocalBoost Production
- [ ] Build the Google Forms: free-check request (with consent checkbox) and onboarding (`templates/onboarding-form.md`)
- [ ] Set up the WhatsApp Business number (checklist in `04-contact-and-consent.md`)
- [ ] **Test:** Saad takes 3 real leads from Discovered to a drafted approval, with nothing copied by hand

**Done when:** one lead moves from discovery to an approval request entirely through the sheet.

## Phase 2 · Days 8–14 — Sales operations

- [ ] Send the first 5–10 approved messages, by email or form, plus in-person visits
- [ ] Print 20 cards with a QR code to the free-check form, for walk-ins
- [ ] Have Claude build the proposal from `templates/proposal.md` once, then reuse it
- [ ] Have Claude build a **demo audit** of one real shop (anonymized) to use as a sales example
- [ ] Run the first weekly review (`05-weekly-review.md`)

**Done when:** an opted-in lead goes through a consistent conversation that ends in a proposal.

## Phase 3 · Days 15–21 — Delivery

- [ ] Claude builds 3 website templates with dummy content: cafe-restaurant, professional-services, retail-shop
- [ ] QC runs `templates/qa-checklist.md` on each template
- [ ] Do a dry run of Get Found on a friendly business, or your own test profile
- [ ] Finalize the handover and monthly report templates

**Done when:** one test project goes from intake to handover with Claude doing the production.

## Phase 4 · Days 22–30 — Real customers

- [ ] Deliver 1–2 real paid projects
- [ ] Track your own hours for each customer
- [ ] Fix the 3 biggest friction points found
- [ ] Decide, based on data: does any bottleneck justify a paid tool (Claude Pro, a WhatsApp API provider, a CRM)?

**Done when:** you have a written, repeatable workflow, real collected revenue, and known hours per customer.

## 30-day targets (goals, not guarantees)

| Metric | Target |
|---|---|
| Leads researched | 10/week |
| Audits completed | 5–10/week |
| Paying customers | 2–3 |
| Concurrent projects | Max 2 |
| Founder hours | ≤ 12/week |
| Measure | **Collected** SAR, not proposals |
