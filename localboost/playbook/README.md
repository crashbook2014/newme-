# LocalBoost Delivery Playbook (internal)

`localboost-delivery-playbook.pdf`: 14 pages, founder-only. It shows how to deliver Get Found, Get Chosen and Stay Current from start to finish, what to review before delivery, Arabic message templates, and fixes for common problems.

Rebuild after editing `build.py`:

```
python3 localboost/playbook/build.py <out-dir>
node localboost/playbook/render.js <out-dir>
```

Then copy the PDF here.
